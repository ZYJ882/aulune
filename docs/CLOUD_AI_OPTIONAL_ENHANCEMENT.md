# Aulune 1.3.0：可选云端 AI 增强

Aulune 1.3.0 恢复并扩展了与 OpenBiliClaw 同类的可选云端模型模式。用户可以在“模型”页填写自己的 OpenAI、Claude、Gemini 或 DeepSeek API Key，选择模型后启用云端增强。未启用、未配置 Key 或调用失败时，信息流会继续使用 1.2.0 的本机规则，不会停止工作。

## 触发方式

云端调用不是后台自动任务，必须由用户显式触发：

| 操作 | 发往云端的数据 | 写回手机本地的结果 |
|---|---|---|
| 内容卡片“AI解析” | 标题、摘要、来源、当前规则主题 | 主题、主题组、系列键和简短推荐理由 |
| 画像页“更新长期画像候选” | 聚合兴趣主题、权重、证据数、会话意图和事件总数 | 长期方向/核心边界的待确认候选 |

Aulune 不会在这些请求中发送 B 站 Cookie、账号令牌、设备标识、完整原始观看历史或完整数据库导出。账号读取授权仍只用于 B 站接口，云端 AI 服务不会读取该授权。

## 安全存储与网络边界

API Key 使用 AndroidX Security Crypto 的 `EncryptedSharedPreferences` 保存，由 Android Keystore 主密钥保护；Key 不写入 APK、Room 数据库、日志或任何中转后端。请求从手机通过 HTTPS 直接发送至用户选择的模型服务。

用户可以随时选择“仅使用本机规则”停用云端增强，或使用“清除加密 Key”删除本地密钥。停用不会删除已经保存到本机的分析结果；需要删除 B 站内容、事件和反馈时，继续使用现有“删除本机 B 站数据”控制。

## 本机规则与云端增强的关系

云端 AI 只增强内容理解和候选文案，最终的内容存储、事件、兴趣生命周期、避雷、主题疲劳、来源多样性和排序仍在手机本地执行。云端分析成功后，Aulune 会将该内容的既有本机事件重分类并重建兴趣画像，避免旧主题继续影响推荐。

## 失败降级

| 情况 | 行为 |
|---|---|
| 未填写或未启用 Key | 显示状态提示，保持本机规则结果 |
| 模型 API 返回错误、限流或网络失败 | 保留原始规则分类与本机画像，不写入部分结果 |
| 模型返回非 JSON 内容 | 解析失败，保留本机规则结果 |
| 用户停用云端模式 | 不再发送新请求；本机规则继续工作 |

## 不包含的能力

1.3.0 不包含端侧 Embedding、端侧 LLM、模型下载、Tokenizer、ONNX、llama.cpp 或向量数据库。云端 API 是用户自带 Key 的可选增强，并不要求服务器或电脑。
