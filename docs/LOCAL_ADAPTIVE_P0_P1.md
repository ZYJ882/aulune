# Aulune 1.1.0：P0/P1 本机自适应闭环

Aulune 1.1.0 将本地信息流从“收藏、标记和简单兴趣权重”升级为可持久化的 P0/P1 自适应闭环。所有数据继续仅保存在 Android 应用私有 Room/SQLite 数据库中，不依赖服务器或云端模型。

## 行为闭环

```text
B 站公开内容 / 用户授权账户内容
  → 内容规范化（来源、作者、主题组）
  → 本机内容库
  → 打开、标记、保存、喜欢、不感兴趣、账户导入证据
  → 标准行为事件与显式反馈
  → 兴趣生命周期与避雷规则
  → 主题疲劳、来源多样性、反馈加权排序
  → 下一次本地信息流
```

## P0：已实现

| 能力 | 行为 |
|---|---|
| 统一行为事件 | 打开、标记、取消标记、保存、取消保存、喜欢、不感兴趣，以及首次导入的收藏/历史/稍后再看均保存为标准事件 |
| 内容元数据 | 内容保存来源键、作者键、系列键和主题组；B 站导入内容会在本地规范化 |
| 账户导入证据 | 收藏夹、观看历史和稍后再看首次同步时生成去重证据，不会因反复同步重复累加兴趣 |
| 显式正反馈 | “喜欢”提高对应主题的本机兴趣权重，并在后续排序中加入主题奖励 |
| 显式负反馈 | “不感兴趣”隐藏当前内容、归档该主题，并为内容、主题、作者和系列建立本机避雷记录 |

## P1：已实现

| 能力 | 行为 |
|---|---|
| 兴趣生命周期 | 新主题先进入 `观察中`；累计 5 条证据或持续 7 天后进入 `活跃`；30 天没有新证据会 `降温` 并减半权重；持续 60 天没有新证据则 `归档` |
| 复活机制 | 归档或降温的主题收到新的正向证据后会重新变为活跃 |
| 主题疲劳 | 最近事件中同主题或同主题组重复出现越多，分数惩罚越强，避免连续推荐同一种内容 |
| 来源多样性 | 同一来源近期出现过多时施加轻度惩罚；从新来源进入的内容拥有小幅探索奖励 |
| 避雷过滤 | 被明确不喜欢的内容、作者或系列会从后续本地信息流中排除；不喜欢主题则大幅降权 |
| 可解释 UI | 卡片显示兴趣处于观察、活跃或降温状态，并说明排序来自正反馈、探索、疲劳或画像证据 |

## 隐私和控制

用户可在“模型”页删除本机 B 站数据；该操作会删除已同步的 B 站内容、关联事件和反馈，并清除内存中的账户读取授权。Aulune 不会自动执行点赞、收藏、投币、评论、删除历史或其他 B 站写操作。

## 当前边界

本版本是 OpenBiliClaw 自适应机制的本地轻量实现，不会训练或修改大模型参数。内容主题仍主要由关键词规则分类；端侧 Embedding、语义相似反馈、系列自动识别、后台批处理和可选本地模型是后续阶段。
