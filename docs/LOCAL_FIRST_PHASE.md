# Aulune 0.8.0：纯手机本地核心（第一阶段）

Aulune 0.8.0 开始将推荐数据从 Compose 会话内存迁移至应用私有的 Room/SQLite 数据库。此版本不需要服务器、电脑或 OpenBiliClaw 后端：内容状态、标记、收藏、打开事件和兴趣权重都只保存在安装该应用的手机中。

## 已实现

| 能力 | 实现方式 |
|---|---|
| 本地内容库 | Room 数据库保存统一内容实体；首次启动会导入内置示例内容 |
| 行为事件 | 打开、标记、取消标记、保存、取消保存均写入 `behavior_event` |
| 兴趣画像 | 每项行为对对应主题更新本地 `interest` 权重和证据数量 |
| 可解释推荐 | 灵感页根据本地兴趣、标记和收藏状态排序，并显示形成原因 |
| 持久化收藏 | 收藏数量、卡片状态和兴趣证据在应用重启后继续保留 |
| 动态画像页 | 画像页显示真实的本机主题、强度和证据数，不再显示固定人格结论 |

## 数据边界

此阶段的所有数据都位于应用私有存储中。当前没有云同步、账户登录、跨设备迁移、跨 App 数据读取或后台抓取。卸载应用会删除其私有数据库；后续版本会增加用户可控的导出、导入与清除功能。

## 当前不包含

本版本尚未接入在线内容 Adapter、WorkManager 增量刷新、分享导入、本地向量检索、端侧 LLM、内容库列表页和跨平台来源。现有 B 站网页入口保持独立，不会向本地画像写入 Cookie 或账号数据。

## 下一阶段

下一阶段将新增本地内容库（收藏、稍后、历史）、用户主动分享链接导入、可控的公开内容来源以及本地导出/导入；后续才考虑在用户明确启用时下载端侧模型。
