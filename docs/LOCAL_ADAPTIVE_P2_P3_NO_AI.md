# Aulune 1.2.0：无模型 P2/P3 本机自适应

Aulune 1.2.0 在 P0/P1 的事件、兴趣生命周期、避雷和疲劳排序之上，加入了不依赖端侧 Embedding、不依赖端侧 AI、也不调用云端模型的 P2/P3 规则能力。所有计算和数据继续保存在 Android 应用私有 Room/SQLite 数据库中。

## P2：规则型内容理解与无模型探索

| 能力 | 实现 |
|---|---|
| 主题归并 | 根据标题、简介、现有主题和来源中的中英文关键词，归并为技术·AI、技术·编程、商业·产品、创造·设计、学习·知识、生活·注意力或娱乐·影视游戏等稳定主题 |
| 主题组 | 对每条内容生成技术、商业、创造、学习、生活或娱乐主题组，用于疲劳和负反馈扩散 |
| 系列识别 | 从标题中移除期数、集数、常见前缀、数字和冒号后缀，形成规则型系列键 |
| 作者键 | 从来源字段的分隔片段中提取稳定作者键；B 站账号数据可保留原始作者键 |
| 会话意图 | 平衡、专注、探索和低噪四种模式由用户选择，保存在手机本地；模式改变排序，不修改兴趣历史 |
| 无模型探索 | 新来源和观察中主题在探索模式获得提升；活跃主题在专注模式获得提升；低噪模式更强调低疲劳和较短内容 |
| 扩展反馈 | 不感兴趣同时保存内容、主题、主题组、作者和系列规则；内容/作者/系列直接过滤，主题组在排序中降权 |

这些规则是透明、确定性的。它们不理解复杂语义，不能替代 Embedding 或 LLM，但不需要模型下载、Tokenizer、推理运行时、服务器或 API Key。

## P3：受控分层画像

P3 将本机画像划分为四层：

| 画像层 | 自动更新 | 用户确认 | 含义 |
|---|---:|---:|---|
| 当前状态 | 是 | 否 | 当前会话意图和内容使用方式 |
| 兴趣层 | 是 | 否 | 活跃、观察、降温与归档兴趣的汇总 |
| 长期方向 | 仅生成候选 | 是 | 当至少有两个活跃主题且累计事件达到 12 条时生成候选 |
| 核心边界 | 否 | 是 | 默认保持空白；不会由点击或同步自动写入 |

低频重建发生在应用启动、生命周期检查、账户内容同步、清除 B 站数据、切换会话意图，以及每累计 5 条新行为事件后。这样不会每次点击都重建完整画像，也不会把一次短期行为直接升级为长期判断。

## 隐私与数据控制

本版本不新增网络请求，不新增 Cookie 读取，不新增本地模型下载。B 站账户数据仍然只有在用户显式授权同步时才读取；清除本机 B 站数据会同时删除已同步内容、事件和反馈，并从剩余事件重建兴趣画像。

## 未实现能力

以下能力明确不属于 1.2.0：端侧 Embedding、向量数据库、Tokenizer、本地模型推理、云端 LLM 内容分析、语义相似检索、自动跨语言语义合并和基于模型的长期人格判断。后续若增加端侧 Embedding，将作为用户主动下载的可选增强包，而不会强制加入 APK。
