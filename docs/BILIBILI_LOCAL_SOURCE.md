# Aulune 0.9.0：B 站作为手机本地信息流数据源

Aulune 0.9.0 新增了 B 站公开内容连接器。用户可以在“灵感”页手动导入公开热门视频，Aulune 会把标题、简介、作者、时长、链接和本地主题保存到应用私有 Room 数据库，再与已有内容统一排序。标记、收藏和打开行为会持续更新本机兴趣权重与推荐理由。

## 本版本的数据流程

```text
用户点击“导入 B 站公开热门内容”
  → B 站公开热门接口
  → Aulune BilibiliPublicConnector
  → 本地主题分类
  → Room/SQLite 本地内容库
  → 本机排序、收藏、标记、行为事件和兴趣画像
```

## 安全与登录边界

| 项目 | 本版本行为 |
|---|---|
| 公开热门内容 | 可手动导入，并保存在手机本地 |
| B 站官方网页登录 | 保留为独立账号管理能力 |
| 登录 Cookie | 不读取、不导出、不复制、不发送给 Aulune 数据连接器 |
| 收藏夹、历史、稍后再看 | 本版本不导入；它们涉及账号授权，须等待正式、明确的授权方式 |
| 本机推荐闭环 | 打开、标记、取消标记、保存、取消保存会记录到本地数据库并调整兴趣权重 |

B 站登录不会自动授权 Aulune 读取账号 Cookie 或跨 App 数据。这样做的目的是避免将高敏感会话凭据从官方网页登录环境复制到应用网络层。即使用户从未登录 B 站，也可以使用公开内容导入与本机个性化排序。

## 内容理解：端侧 AI 的接口边界

`LocalContentClassifier` 是本版本预留的端侧内容理解接口。当前默认实现 `LocalContentUnderstanding` 使用标题、简介和公开分类名称进行关键词主题归类，不联网、不发送内容给云端。例如它会将 AI/编程等内容归为“技术 · AI”，将设计/摄影等内容归为“创作 · 表达”。

后续若用户主动下载端侧模型，可以实现同一接口替换规则分类器。模型必须运行在应用本机并可由用户删除；不会默认使用 OpenAI、Gemini 或其他云端 API。端侧模型的下载、哈希校验、内存管理、设备基准测试和用户开关将在独立版本实现。

## 当前限制

本版本只提供 B 站公开热门内容的手动导入；不会承诺精准个性化推荐、后台常驻抓取、自动同步账户历史或绕过平台登录/风控。每次导入会尽量保留同一内容已经存在的收藏、标记和隐藏状态，避免刷新覆盖用户本地选择。
