# Aulune v0.5.0

## 版本定位

v0.5.0 是 Aulune 的视觉标识更新版本。应用启动器图标升级为独立设计的抽象极光交织符号，以深午夜蓝背景搭配象牙白至薄荷青的柔和渐变，适合在 Android 启动器的小尺寸场景中保持辨识度。

## 更新内容

| 项目 | 说明 |
|---|---|
| 新启动器图标 | 使用两条不对称圆润光带构成抽象中心菱形留白的独立标记 |
| 多密度资源 | 已适配 `mdpi`、`hdpi`、`xhdpi`、`xxhdpi` 与 `xxxhdpi` 启动器尺寸 |
| 品牌边界 | 新图标不含文字、机器人、对话气泡或任何现有 AI 产品的商标图形 |
| 原有能力 | 保留多模型工作台、B 站官方网页会话和四方式认证入口 |

## 安装

下载本 Release 的 `Aulune-v0.5.0.apk`，在 Android 8.0（API 26）或更高版本设备上安装。若启动器仍显示旧图标，请尝试刷新桌面缓存或重启设备；Android 启动器可能会暂存图标缩略图。

## 已知限制

本版本为 Debug 构建，采用本地调试签名，仅适合个人测试。新图标是独立抽象设计，不关联、不暗示也不复制任何第三方品牌标志。
