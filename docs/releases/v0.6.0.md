# Aulune v0.6.0

## 版本定位

v0.6.0 为 Aulune 更新了更贴合产品能力的独立启动器图标。新标记以“汇入、理解、成长”为视觉逻辑：中心圆核象征用户画像，左下三条汇入曲线象征推荐信息流，右上开放弧线与三枚渐进节点象征 AI 在本地持续学习和自我演进。

## 更新内容

| 视觉元素 | 对应能力 |
|---|---|
| 中心圆核 | 汇聚用户长期偏好、主题和行为线索形成的个人画像 |
| 左下汇入曲线 | 多来源内容被筛选、整理并推荐到个人信息流 |
| 右上开放生长弧线 | AI 随使用反馈持续推理、学习和扩展理解边界 |
| 深靛蓝、薄荷绿与青蓝 | 本地可信、清晰洞察与智能成长的视觉氛围 |

新图标已适配 Android `mdpi`、`hdpi`、`xhdpi`、`xxhdpi` 与 `xxxhdpi` 启动器资源。图标为独立原创抽象图形，不含文本、品牌名称或第三方商标标志。

## 安装

下载本 Release 的 `Aulune-v0.6.0.apk`，在 Android 8.0（API 26）或更高版本设备安装。若桌面仍显示旧图标，可尝试刷新启动器缓存、重新添加桌面图标或重启设备。

## 已知限制

本版本为 Debug 构建，采用本地调试签名，仅适合个人测试。除图标与版本号外，应用的多模型工作台、B 站官方网页会话和四方式官方认证入口均保持不变。
