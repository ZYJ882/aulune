# Aulune v0.2.0

## 版本定位

v0.2.0 是 Aulune 的多模型工作台版本，将早期离线界面扩展为可配置的本地直连 AI 客户端。

## 新增内容

| 能力 | 说明 |
|---|---|
| 多模型配置 | 支持 OpenAI、Claude、Gemini、DeepSeek |
| 对话工作区 | 多轮文本消息、生成状态和模型切换 |
| 直连请求 | 从设备通过 HTTPS 请求对应服务商，不使用中转服务 |
| 本地边界 | API Key 只保存在应用内存，退出进程后清除 |

## 安装

下载本 Release 的 `Aulune-v0.2.0.apk`，在 Android 8.0（API 26）或更高版本的设备上安装。安装后进入“模型”页填写自己拥有的 API Key 和可用模型名称，再进入“对话”页使用。

## 已知限制

本版本不包含 B 站账号管理、流式输出、文件或图片上传、工具调用和跨设备同步。该 APK 为 Debug 构建，使用本地调试签名，适合个人测试。
