# Aulune v0.3.0

## 版本定位

v0.3.0 是 Aulune 的账号管理增强版本，在多模型工作台基础上加入 B 站官方网页会话入口。

## 新增内容

| 能力 | 说明 |
|---|---|
| 官方账号中心 | 在 Aulune 内访问 B 站官方账号中心 |
| 创作中心 | 快速进入 B 站官方创作中心 |
| 消息页 | 访问官方消息管理页面 |
| 受控网页会话 | 仅允许 HTTPS 下的 B 站可信域名导航 |
| 会话清除 | 清除 Aulune 容器内 Cookie，不影响官方客户端 |
| 保留多模型 | 继续支持 OpenAI、Claude、Gemini、DeepSeek |

## 安装

下载本 Release 的 `Aulune-v0.3.0.apk`，在 Android 8.0（API 26）或更高版本的设备上安装。进入“模型”页，点击“B 站账号管理”即可打开官方账号管理页面。

## 已知限制

本版本不提供 Cookie 导入、多账号程序化切换、自动投稿、自动评论、消息抓取或绕过 B 站风控。所有账号能力以官方网页在当前设备和网络环境中实际允许的范围为准。该 APK 为 Debug 构建，使用本地调试签名，适合个人测试。
