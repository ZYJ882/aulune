# Aulune v0.4.0

## 版本定位


## 新增内容

| 入口 | Aulune 中的体验 | 认证处理方式 |
|---|---|---|
| 扫码登录 | 二维码登录说明与“打开官方扫码登录”操作 | B 站官方页面实时生成二维码并完成确认 |
| 密码登录 | 账号、密码与安全验证的引导界面 | 在 B 站官方页面输入与验证 |
| 短信登录 | 地区、手机号和验证码的流程说明 | 在 B 站官方页面输入、发送与验证 |
| Cookie | 会话凭据风险说明与官方登录入口 | 不支持粘贴、验证、导入或导出 Cookie |

## 安全边界

Aulune 不读取、不记录、不上传、不解析也不持久化账号密码、短信验证码、完整 Cookie、`SESSDATA`、`bili_jct`、CSRF 或访问令牌。所有真实认证均在隔离的 B 站官方网页会话内完成。网页会话只允许 HTTPS 下的 B 站可信域名导航；“清除网页会话”只影响 Aulune 容器，不影响设备上的 B 站官方客户端。

## 安装

下载本 Release 的 `Aulune-v0.4.0.apk`，在 Android 8.0（API 26）或更高版本设备安装。进入“模型”页，点击“选择登录方式”，选择相应入口后再打开官方认证页面。

## 已知限制

本版本不支持 Cookie 导入、多账号程序化切换、自动投稿、自动评论、消息抓取、直接调用未公开登录接口或绕过 B 站安全验证。APK 为 Debug 构建，采用本地调试签名，仅适合个人测试。
